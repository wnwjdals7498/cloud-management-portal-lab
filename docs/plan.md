# PHP 관리포털 구축 계획

## 목표와 선행 조건

PHP·CodeIgniter·MySQL 관리포털에서 회원 신청부터 Hyper-V VM 작업, 사용 기간 기반 청구까지 검증한다. Windows 자동화는 `windows-private-cloud-lab`과 연결한다. 이 프로젝트에서 확인한 데이터베이스 스키마·API 계약·테스트 데이터를 이후 Node 구현과 공유한다.

## 단계

1. 공식 지원 버전, 실행 환경, 라이선스와 보안 가이드를 확인한다. 테스트 계정과 예제 데이터만 준비한다.
2. 회원·관리자 역할, VM 요청·작업 상태·사양 변경 이력·청구 데이터의 계약을 정의한다. 로그 세부 형식은 구현 전에 결정한다.
3. 관리자 계정 생성과 회원 관리, 인증·인가를 구현한다. 회원은 본인 VM만 조회·조작하도록 검증한다.
4. VM 신청 시 승인 대기 없이 생성 작업을 시작한다. PowerShell/Hyper-V 호출, 작업 상태, 실패·재시도·복구를 연결한다.
5. 시작·중지·재시작·삭제·사양 변경을 두 포털에서 검증한다.
6. 생성부터 삭제까지의 기간과 실제 적용 사양으로 월별 사용분을 계산한다. 매월 1일 전월 청구서를 생성하고, 전원 상태와 무관한 계산을 검증한다.
7. Slack 알림과 제한된 이메일 발송을 검증한다. SMS 테스트 환경과 Toss Payments 공식 테스트 환경의 사용 가능성을 확인한 뒤 조건부 범위를 결정한다.
8. 입력 검증, 권한 우회, 민감정보 노출과 주요 작업 실패 사례를 점검한다. 재현 가능한 테스트 결과를 남긴다.

## 완료 확인

- 회원 신청 뒤 실제 테스트 VM 생성 작업이 즉시 시작된다.
- 회원·관리자 권한과 다섯 VM 조작이 실제 Hyper-V 상태와 일치한다.
- 사양 변경 구간과 생성·삭제 시점을 반영한 전월 청구서가 매월 1일 생성된다.
- 테스트 결과가 실제 구현 상태와 일치하고 민감정보가 로그·공개 자료에 포함되지 않는다.

## 이후 결정

정확한 제품 버전, 가상 단가, 로그·테스트 증거 세부 형식, SMS 환경, 테스트 PG 연동 여부는 해당 단계 전에 결정한다. 실제 결제와 VM 외 추가 상품은 구현하지 않는다.
