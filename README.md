# cloud-management-portal-lab

> 상태: 계획 단계. 관리포털 구현·검증 전.

PHP·CodeIgniter·MySQL로 VM 관리포털을 새로 구현하는 실습 프로젝트다. 회사 원본 코드와 데이터는 사용하지 않는다. 실제 실행 서비스는 허용된 사설망에서만 접근하며, 공개 저장소에는 코드와 안전한 검증 자료만 둔다.

## 계획한 범위

- 회원·관리자 포털. 공개 회원가입 없이 관리자가 테스트 회원을 생성·관리한다.
- 회원 신청 직후 관리자 승인 없이 Hyper-V VM 생성 작업을 시작한다.
- 회원은 본인 VM, 관리자는 모든 회원 VM의 시작·중지·재시작·삭제·사양 변경을 수행한다.
- 실제 VM 사양과 생성부터 삭제까지의 기간으로 가상 단가 기반 월별 청구서를 매월 1일 생성한다. 전원 정지 시간도 사용 기간에 포함하고, 사양 변경 시점을 기준으로 요금 구간을 나눈다.
- Slack 알림, 제한된 이메일 발송 테스트, SMS 테스트 환경 조사.
- Toss Payments 테스트 연동 가능성을 확인한다. 제약이 크면 청구서 관리까지만 구현한다. 실제 금전 결제는 하지 않는다.

VM 외 별도 스토리지·로드밸런서·방화벽 상품은 범위에서 제외한다. 세부 버전과 요금 단가는 아직 정하지 않았다.

[단계별 계획](docs/plan.md)을 따라 현재 상태와 검증 결과가 바뀌면 이 README를 갱신한다.
